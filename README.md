# Adventures-in-Backrooms-USSR

Это прототип игры Adventures in Backrooms USSR для команды разработчиков.
Как запустить проект в юнити:
1. Переходите в релизы.
2. Скачиваете ZIP-архив последней версии прототипа.
3. Windows 10 и 11: после загрузки архива найдите его в проводнике и нажмите по нему ПКМ, затем кнопку "Извлечь всё...". Путь извлечения файлов оставьте таким же, и нажмите "Извлечь".
4. Перейдите в Unity Hub и нажмите на Projects в левой панели хаба.
5. Слева от кнопки New project найдите кнопку Add и нажмите на неё.
6. В появившейся панели выбора нажмите Add project from disc
7. В появившемся окне проводника выберите извлечённую папку с проектом и нажмите Open.
8. Всё, у вас в листе проектов появится прототип Adventures in Backrooms USSR.
